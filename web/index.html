Guia de Testes dos Cenarios Distribuidos

Utilize os recursos de interface acima para simular falhas de infraestrutura ou envie requisicoes aos endpoints padrao (via Swagger ao lado ou curl):

1. Tolerancia a Falhas Bizantinas (2f + 1) Infraestrutura
Simula um controlador fornecendo respostas falsificadas (ataque ou erro intermitente).
Acao na Interface: No card do Controlador 3 acima, clique em Corromper.
Endpoint Padrao: GET /api/status
Log Python no Terminal:
[ERROR] (Middleware) [SEGURANCA] Falha Bizantina detectada no No 3. Resposta descartada.
2. Failover Crash-Stop (Queda do Primario) Infraestrutura
Simula queda abrupta do no primario durante o processamento de comando do cliente.
Acao na Interface: No card do Controlador 1 (Lider) acima, clique em Derrubar.
Endpoint Padrao & Payload: 
POST /api/command/dispense_food
{"quantidade": 50.0}
Logs Python no Terminal:
[WARNING] (Middleware) No Primario 1 inalcancavel... Iniciando failover transparente. [INFO] (Middleware) No 2 promovido com sucesso a novo Lider Primario.
3. Idempotencia (Semantica Exactly-Once) Interacao / Rede
Comprova que retransmissoes de rede com mesmo command_id nao duplicam atuações fisicas.
Como Executar: Dispare duas vezes consecutivas o comando abaixo com o mesmo UUID.
Endpoint Padrao & Payload: 
POST /api/command/dispense_food
{"quantidade": 50.0, "command_id": "00000000-0000-0000-0000-000000000001"}
Log Python no Terminal (2a execucao):
[WARNING] (Controller-Node1) No 1: Comando duplicado ignorado por idempotencia (command_id=00000000-0000-0000-0000-000000000001)
4. Sanitizacao de Entradas (Validacao de Dominio) Interacao / Entrada
Verifica a rejeicao de dados anomalos pelo validador antes de atingir o banco relacional.
Endpoint Padrao & Payload: 
POST /api/command/dispense_food
{"quantidade": -50.0}
Log Python no Terminal (HTTP 400):
[WARNING] (WebGateway) Falha na validacao/execucao do comando dispense_food: Quantidade de racao invalida: -50.0g...
